Abstract Base Classes: Enforcing a Contract

Right now, nothing stops a future subclass of BankAccount from forgetting to override withdraw — it would just silently inherit the parent's version, maybe wrongly. Today you make that a loud, immediate error instead of a quiet bug.

The core idea

Every override so far has been a convention — CheckingAccount.withdraw exists because you remembered to write it, not because Python required it. An abstract base class (ABC) turns that convention into a rule Python itself enforces: mark a method @abstractmethod in a class that inherits from ABC, and Python refuses to instantiate any subclass that hasn't provided its own version — raising TypeError at the moment of creation, not three months later when that code path finally runs.

This is the same idea as an interface in Java/TypeScript, but Python's version is deliberately minimal: no separate keyword, just abc.ABC as a base class and @abstractmethod as a decorator.

Anatomy: a required method

from abc import ABC, abstractmethod

class Account(ABC):
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    @abstractmethod
    def account_type(self):
        ...          # no implementation — subclasses MUST supply one

class SavingsAccount(Account):
    def account_type(self):
        return "Savings"

Account("Dhrubo", 100)          # TypeError: Can't instantiate abstract class
                                 # Account with abstract method account_type
SavingsAccount("Dhrubo", 100)   # fine — the contract is satisfied

Compare this to a normal (non-abstract) method with a pass body: that version would let Account("Dhrubo", 100) succeed silently, and any subclass that forgot to override it would too — the bug only shows up later, when account_type() returns nonsense. @abstractmethod moves the failure to the earliest possible moment: object creation.

The test to apply
When a method exists purely so subclasses override it, ask: do I want Python to enforce that override, or just document the convention? If a missing override should be impossible, not just unlikely, that's @abstractmethod.
