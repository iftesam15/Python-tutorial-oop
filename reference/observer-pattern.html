Observer Pattern

One-to-many subscription: a publisher notifies every current subscriber when something happens. Subscribers join and leave at runtime. Also called Event-Subscriber or Listener.

Parts

RoleJobIn the bank
Publisher (subject) Owns interesting state; notifies after a change BankAccount.deposit / withdraw
Subscriber (observer) One update (or a callable) the publisher understands email alert, audit log, platinum banner
Subscription list Instance list (or map of event kind → listeners) EventManager composed into the account
Client Creates both sides and calls subscribe Factory, CLI, tests

When to reach for it

  • A state change should trigger side effects in other objects, and you do not know the set in advance.
  • Listeners must join and leave at runtime (opt out of SMS, attach a test spy).
  • Adding a new reaction today would mean editing deposit / withdraw (OCP smell).

Skeleton (composition — preferred here)

class EventManager:
    def __init__(self):
        self._observers: dict[str, list] = {}

    def subscribe(self, kind: str, observer) -> None:
        self._observers.setdefault(kind, []).append(observer)

    def unsubscribe(self, kind: str, observer) -> None:
        listeners = self._observers.get(kind, [])
        if observer in listeners:
            listeners.remove(observer)

    def notify(self, kind: str, event) -> None:
        for observer in list(self._observers.get(kind, [])):
            observer.update(event)

Iterate a copy of the list so a listener can unsubscribe during notify without skipping the next one. Keep the list on the instance — a class-level _observers = [] is shared by every account (Day 2).

Python shapes (pick the smallest that fits)

# 1. Stateless: a function is an observer
account.events.subscribe("deposit", lambda e: print(e.message))

# 2. Stateful: a class with update()
class LowBalanceAlert:
    def __init__(self, threshold: float):
        self.threshold = threshold
    def update(self, event) -> None:
        if event.account.balance < self.threshold:
            print("low balance")

# 3. Stdlib you already use: logging
# Logger = publisher, Handler = observer
logger.addHandler(logging.StreamHandler())

Not the same as

PatternIntent
Strategy One collaborator; context needs the result (interest, fee). Observer: many collaborators; publisher does not need a return value.
Notifier (DIP) How to send one message. Observer: who cares that something happened (zero, one, or many).
Mediator A hub that coordinates two-way talk among components. Observer is one-way: publisher → subscribers.
