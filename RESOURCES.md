# Python OOP Resources

## Knowledge

- [Python Classes: The Power of Object-Oriented Programming — Real Python](https://realpython.com/python-classes/)
  Clear, thorough intro to classes, instances, attributes, methods. Use for: Day 1-2 material (classes, instance vs class attributes).
- [Object-Oriented Programming (OOP) in Python 3 — Real Python](https://realpython.com/python3-object-oriented-programming/)
  Broader OOP walkthrough including inheritance. Use for: inheritance and polymorphism days.
- [Object-Oriented Programming (OOP) — Learning Path — Real Python](https://realpython.com/learning-paths/object-oriented-programming-oop-python/)
  Curated path from classes through design patterns, magic methods, and SOLID. Use for: overall spine of the curriculum — check off sections as we go.
- [9. Classes — The Python Tutorial (official docs)](https://docs.python.org/3/tutorial/classes.html)
  The canonical reference for Python's class semantics (scoping, namespaces, multiple inheritance/MRO). Use for: whenever something needs the authoritative answer, not just a tutorial's simplification.
- [Python OOP Tutorials — Working with Classes (playlist) — Corey Schafer](https://www.youtube.com/playlist?list=PL-osiE80TeTsqhIuOqKhwlXsIBIdSeYtc)
  6-part video series: classes/instances, class variables, classmethods/staticmethods, inheritance, dunder methods, property decorators. Use for: a video-first pass before or after a lesson, especially for dunder methods and properties.
- [SOLID Design Principles: Improve Object-Oriented Code in Python — Real Python](https://realpython.com/solid-principles-python/)
  SOLID explained with before/after Python refactors, not abstract UML. Use for: the SOLID-focused lessons later in the path (job-interview relevant).
- [abc — Abstract Base Classes — Python docs](https://docs.python.org/3/library/abc.html)
  Canonical, short reference for `ABC`/`abstractmethod` semantics. Use for: Day 8 material (enforcing a shared interface).
- [Design Patterns in Python — Refactoring.Guru](https://refactoring.guru/design-patterns/python)
  Conceptual + real-world Python code for all 22 classic GoF patterns. Use for: Factory/Strategy/Observer lessons in the later, harder projects.
- [RefactoringGuru/design-patterns-python (GitHub)](https://github.com/RefactoringGuru/design-patterns-python)
  Runnable source for the above. Use for: pulling a working example to compare against the user's own attempt.

## Wisdom (Communities)

- [r/learnpython](https://reddit.com/r/learnpython)
  Beginner-friendly, high-signal, good for "does my design make sense" or "why did this error happen" questions. Use for: when stuck on a specific project bug or wanting a second opinion on a design.
- [Python Discord](https://www.pythondiscord.com/)
  Large (400k+), staffed help channels, code jams/challenges. Use for: real-time feedback while working, and community events once past the basics — good for the "wisdom" side of the mission (talking through design decisions with other people, which is what interviews demand).

## Gaps
- No community/resource yet specifically for mock OOP interview practice (e.g. "design a parking lot" style questions). Worth searching for once the user is past the fundamentals and into the SOLID/patterns portion of the path.
